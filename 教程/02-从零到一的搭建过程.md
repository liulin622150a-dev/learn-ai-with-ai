# 从零到一的搭建过程

这套知识库由学习目标、课程、实际问答、记录与复盘逐步形成。这里分享可复用的方法，不公开作者的私人聊天和评价。

## 第一步：把学习目标说清楚

先说明想理解什么、目前基础怎样、能投入多少时间，以及暂时不需要什么。目标先落在能解释概念、能使用工具、能核查输出上，不急着确定最终职业方向。

把“怎样教我”单独写进学习习惯文件。公开项目只保留填写方法，每个人自己填写。

## 第二步：确定路线和边界

先按模块排顺序：认识AI → 理解大模型 → 人机协作 → 多模态 → 知识库与智能体 → 判断力。再把模块拆成每周与每课。路线提供方向，实际进度以完成情况为准。

本包已经完成第1—7周课程整理，读者可以直接使用，不必重复搭建文件夹。

## 第三步：把课程变成能打开的页面

只列“今天学机器学习”不够。每课要有可读教材、核心问题、练习和完成后记录的位置。教材保持一个主要来源，用链接或嵌入引用，避免同一概念多份解释互相冲突。

首页只保留当前入口、周目录和常用查阅位置。让学习者一眼知道从哪里开始，比增加很多栏目更有用。

## 第四步：边学边检验

基本顺序是：少量讲解 → 自己作答 → 指出问题与依据 → 补充解释 → 用新任务复检。

检验要有完整材料和明确要求。不能先说出答案再把复述当成独立掌握，也不能只用简单的对错题证明复杂能力。若题目本身有歧义，先修正题目。

## 第五步：分开课程、笔记与个人证据

- 课程：告诉你学什么、怎样练。
- 核心笔记：用白话保留主要概念，方便回查。
- 学习记录：保存你真实做过什么、得到什么帮助。
- 问题清单：保留暂时没理解或需要再验证的内容。

课堂结束、实操完成、能力通过分别记录。个人证据保留在自己的副本，不变成别人的默认成绩。

## 第六步：用多个聊天分担工作

主聊天负责路线与整理，每周聊天负责当周教学。每个新聊天先读少量交接文件，避免依赖整段历史。聊天之间不假定自动知道彼此内容，重要信息落到文件里。

具体交接见[Codex与Obsidian协作](03-Codex与Obsidian协作.md)。

## 第七步：根据真实问题改进

遇到术语不一致，就对照原课程统一必要用词；笔记太长，就保留核心结论并链接详细教材；新聊天不了解进度，就补交接信息。每次说明问题、改动范围与依据，再执行必要调整。

不要为了“整理”不断改文件，也不要把读过资料等同于学会。公开时另建副本，保留课程与方法，剥离个人信息。这正是本预览的整理方式。

## 想亲手搭一次：最小可用版本

直接学习本项目时不用做这一段。如果你想复现搭建过程，请在本项目之外新建一个练习文件夹，避免改到正在学习的副本。

### 1. 建立文件夹

在电脑文件管理器中新建“我的AI学习练习库”，用Obsidian的“打开已有文件夹”打开它。先只建立下面四个文件夹：

```text
我的AI学习练习库/
├─ 01-首页/
├─ 02-课程/
├─ 03-教材/
└─ 04-记录/
```

这些名称是搭建演示，不要求把本项目现有目录重命名。

### 2. 创建一份教材

在“03-教材”里新建“认识AI.md”，填入：

```markdown
# 认识AI

AI系统根据目标，从输入中推断如何产生预测、内容、建议或决定。

它不是所有自动化的统称。普通定时开关可以只按固定时间执行，不需要AI。

待核查：为这个定义补充可靠来源，确认解释没有超出来源。
```

这只是演示短文。正式教材应补可靠来源，不能把AI的第一稿直接当作已核实资料。

### 3. 创建一份课页

在“02-课程”新建“第1课.md”，填入：

```markdown
# 第1课：认识AI

## 教材

![[03-教材/认识AI]]

## 任务

用自己的话说明输入、目标和输出各是什么。
普通定时开灯一定属于AI吗？说明理由。

## 记录

完成后把原答、获得的帮助和仍不懂的地方写入“04-记录”。
未做的项目不要写完成。
```

`[[文件路径]]`用于跳转，前面加`!`用于把笔记内容嵌入当前页。路径从仓库根目录开始，不带电脑用户名。

### 4. 创建唯一入口

在“01-首页”新建“今日学习.md”，填入：

```markdown
# 今日学习

当前入口：[[02-课程/第1课|开始第1课]]

学习记录尚未填写。先学习与作答，再确认是否进入下一课。
```

### 5. 让Codex检查，不急着扩大

把练习库作为可访问的项目文件夹，告诉Codex：

> 请读取这份练习库，核对首页能否进入第一课、课页能否显示教材、题目是否有明确对象。核对教材定义的可靠来源。先报告具体问题和拟修改内容，不要批量扩写课程或编造我的学习结果。

自己在Obsidian阅读视图点击一次首页链接，确认课页出现教材，而不是只剩文件名。若打不开，检查文件名、文件夹层级和链接拼写。

### 6. 保存第一份真实记录

作答后，在“04-记录”新建“第1课记录.md”，写下实际原答、提示或解释、修正后的理解和待复检项。让Codex先展示草稿，由你确认后保存。最后再讨论第二课学什么。

这样就完成了最小闭环：入口 → 课程 → 教材 → 作答 → 检查 → 记录。以后再逐步增加周目录、总笔记、术语和关系图；没有实际需要的栏目可以先不建。
