# 与ai学习ai

**从一份整理好的知识库开始，借助AI理解、练习、核查，再留下自己的学习记录。**

这是面向AI初学者的学习项目。它分享的不只是课程，也包括怎样从零搭建知识库、怎样让Codex配合Obsidian管理学习，以及怎样逐步改进自己的学习方法。

> 这是《与ai学习ai》的首个公开版本。项目可授权内容采用[CC BY-SA 4.0](LICENSE.md)。提供第1—7周共49课；12周路线保留，第8—12周的每日课程尚未配齐。不含作者的个人习惯、成绩、作答与私人媒体。

[下载完整学习包](https://github.com/liulin622150a-dev/learn-ai-with-ai/archive/refs/heads/main.zip) · [项目主页](https://github.com/liulin622150a-dev/learn-ai-with-ai)

## 先开始，再慢慢理解整套方法

1. 阅读[快速开始](教程/01-快速开始.md)，用Obsidian打开本项目里的 **知识库** 文件夹。
2. 打开[今日学习](知识库/01-首页/今日学习.md)，进入第1课。教材与题目已经整理好。
3. 用Codex读取对应课页，讲解、提问、评价；确认后保存你自己的记录。

不需要编程基础，不强制一天一课。文字部分可以先学习；涉及图片、音频、视频的实际体验，需要另备工具和非私密素材。

## 课程方向

|周次|内容|
|---|---|
|第1周|AI、规则与学习、机器学习、深度学习、生成式AI与模态|
|第2周|分类、发展、能力边界、完整产品、核查与方案选择|
|第3周|Token、参数、训练、推理、Transformer与注意力|
|第4周|上下文、概率生成、幻觉、能力边界与评测|
|第5周|提示词、约束、追问、总结、比较与改写|
|第6周|研究、来源、工具比较、提示词测试与改进|
|第7周|图像、语音、视频的理解与生成，以及证据核查|
