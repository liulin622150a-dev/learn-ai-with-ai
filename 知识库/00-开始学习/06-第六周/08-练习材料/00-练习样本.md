# 第六周练习样本

这些材料沿用第六周计划草案，均为人为编写的教学情境，**不是现实活动信息，也不是已完成的作业**。可以用于预习或课堂讲解；正式独立检验另用完整、未提前见过的新材料。

### 来源核查样本

- 教学虚构：河岸阅读空间管理方2026-08-31公告，9月周六开放一、二层，9:00—17:00，需预约。
- 同一管理方2026-09-04更新：9月6日至20日二层暂停开放进行维修，一层仍按原时间开放；这段期间入馆无需预约。
- 一份2026-09-10社区转述称，9月12日两层均开放且无需预约；未提供新的管理方依据。

任务：给定到访日期为2026年9月12日（周六），核查朋友的“两层都能去、不必预约”这句说法，写结论及对应证据。材料同时含多条说法、日期变化和部分一致信息，不能只凭最新转述的日期作判断。这里练的是给定材料中的核查，不足以证明现实场馆状态。

### 总结样本

完整原文使用[[00-开始学习/06-第六周/08-练习材料/01-公开练习材料#S1：常见任务|总结材料S1]]或[[00-开始学习/06-第六周/08-练习材料/01-公开练习材料#S2：边界任务|总结材料S2]]。

任务：为准备参加的人整理两条到场准备要点，保留影响参加判断的条件和明确原因，不添加原文没有的时间或安排。材料提供合并、取舍及状态、因果、限定词核对空间，不能只检验换句话说。

### 比较样本

情境：今晚约35分钟，想先理解一个概念，再完成至少一道独立应用练习；可以阅读和打字。

| 资料 | 给定信息 |
| --- | --- |
| A | 白话概念说明，预计18分钟，有解释完整的例子，无练习 |
| B | 两个应用任务及参考答案，预计22分钟包含作答与反馈；第一题预计8分钟、第二题14分钟，两题可独立选做；不提供入门概念介绍 |
| C | 案例演示文章，预计阅读12分钟；附一道独立练习，练习耗时未给出 |

任务：提出有依据的学习安排，说明时间估计和未确认事项。允许不同安排，只按目的、材料与条件评价，不把某个推荐组合当唯一答案。

### 改写样本

> 你昨天发的安排我只看了交通那段，住宿那段还没看。酒店名字我记不清，不要帮我订。我周五能不能去还不确定，今晚只能讨论路线，费用等我看完住宿资料再谈。你先给我一个从车站到场馆的具体走法，别一下发一堆东西。

任务：改成发给朋友的礼貌、清楚消息，保留已读与未读范围、暂不订房、是否能去未定、当前讨论范围和所需帮助，不新增承诺。原文确有语气与组织上的调整空间；不要求额外事实或“为改而改”。
