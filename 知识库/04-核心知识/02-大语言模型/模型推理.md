# 模型推理

## 1. 一句话说明

推理是使用训练好的模型和已有参数，处理输入并计算本次输出的过程。

## 2. 生活类比

练习之后做一道新题，是使用已经形成的能力。这里仅类比训练与使用的区别，不表示模型像人一样思考。

## 3. 正式概念

推理描述使用阶段，不是新的模型类型或学习方式。图片分类、数值预测和生成文字都可以属于推理。训练通常按学习信号更新参数；推理通常使用已有参数。聊天纠正会成为输入，产品也可能保存记忆或反馈；这些现象均不能单独证明当前对话立即更新底层参数。

## 4. 可视化原理

已训练模型＋已有参数＋输入 → 本次计算 → 类别／数值／生成内容

## 5. 现实例子

工厂白天用模型检查新照片，判断有无缺陷，是推理；晚上利用错判照片训练并调参，是训练。输出是几个汉字，不足以证明底层模型在做逐Token续写。

## 6. 常见误解

- 推理只指聊天模型写答案：图片分类也是推理。
- 回答结束后才开始推理：生成中的计算已是推理。
- 对话纠正等于即时训练：还需确认参数是否更新。
