# 什么是大语言模型

## 1. 一句话说明

大语言模型是以语言为主要模态、从大量文本学习 Token 与上下文关系的大规模模型。

## 2. 生活类比

它像一个读过很多文本的语言助手：有的擅长读取与表示文本，有的擅长按开头续写，还有的会先读一段再生成另一段。它们共同学习语言模式，却不等于内置了一本每页都可靠的事实百科。

## 3. 正式概念

大语言模型（Large Language Model, LLM）是在大量文本上训练，学习 Token 序列、语言模式和上下文关系的大规模神经网络。文本经 Tokenizer 编码为 Token，它们可对应词、子词、字符或标点等处理单位。现代 LLM 多使用 Transformer：encoder-only 主要形成上下文表示，decoder-only 擅长生成序列，encoder-decoder 则先编码输入再生成输出。

分类时要分两个维度：`AI → 机器学习 → 深度学习` 是方法/技术谱系；“生成式”描述输出能力，而“大模型、基础模型、LLM”分别侧重规模、跨任务适应性或语言模态。生成式 decoder-only LLM 位于这些维度的交集，但并非所有 LLM 都属于生成式 AI。

## 4. 可视化原理

```text
文本 → Tokenizer → Token 序列 → Transformer
                                      ├→ encoder-only：上下文表示
                                      ├→ decoder-only：反复预测后续 Token
                                      └→ encoder-decoder：输入表示→输出序列

方法谱系：AI → 机器学习 → 深度学习
能力标签：生成式 ↔ decoder-only LLM（常见交集，不是全部 LLM）
```

## 5. 现实例子

要求一个生成式 decoder-only LLM 把公开通知改写成待办清单时，模型会利用提示和原文的上下文，反复预测后续 Token。它可以输出结构清楚的文本，但可能把“建议”改成“必须”，所以需逐条对照原通知。
提示能改变生成方向，但不能把未提供的事实自动变成已验证知识。

## 6. 常见误解

- 误解一：LLM 就是一个搜索引擎。它的基本动作是根据上下文生成，不是默认从可核查网页取回答案。
- 误解二：所有 LLM 都只是反复预测下一 Token 的续写器。这一说法适合许多生成式 decoder-only 模型，但不能概括 encoder-only 和 encoder-decoder 架构。
- 误解三：LLM 都是生成式 AI。“语言模型”描述主要处理对象，不自动规定输出能力；需再看架构与任务。
- 误解四：“大”保证每个答案都正确。规模不能消除幻觉、偏见或上下文不足。

## 7. 与其他知识的联系

LLM 通常建立在 [[什么是神经网络|神经网络]]与 [[什么是深度学习|深度学习]]之上；其中用于生成内容的 decoder-only 等模型与 [[什么是生成式AI|生成式 AI]] 相交，而不是所有 LLM 都被该能力标签覆盖。当模型同时处理图像或音频时，还会与 [[文本图像语音与视频|多模态]] 学习相连。

1. 复述：用“Token 序列”和“上下文”解释 LLM 学习什么。
2. 比较：LLM 的生成与搜索引擎取回网页有什么不同？
