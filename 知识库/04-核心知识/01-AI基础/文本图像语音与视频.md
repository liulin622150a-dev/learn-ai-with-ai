# 文本、图像、语音与视频

## 1. 一句话说明

模态是信息的表现形式，多模态 AI 能把文本、图像、语音或视频联合处理。

## 2. 生活类比

人看菜谱时可以读文字、看成品图，还能听厨师讲解。每种通道都提供不同线索：文字说明分量，图像展示外观，声音补充节奏。多模态模型像把这些线索放到同一张工作台上对照。

## 3. 正式概念

模态（Modality）是数据或信号的类型。文本在存储或输入时通常以字符或字节表示，进入语言模型前常由 Tokenizer 编码为 Token，Token 才是模型处理单位；图像表示空间中的像素和形状；语音是随时间变化的声音信号；视频包含画面的时间顺序，也可包含音频。多模态（Multimodal）系统能接收或生成不止一种模态，并学习它们之间的对应关系。

## 4. 可视化原理

```text
文本（字符/字节）→ Tokenizer → Token ─┐
图像             → 视觉编码      ─├→ 联合表示 → 多模态输出
语音             → 音频编码      ─┤
视频             → 时空编码      ─┘
```

## 5. 现实例子

给系统一张公共场所指示牌照片，要求它读出文字并用语音播报，这条链路包含图像输入、文本识别与语音输出。若照片反光或遮挡，文字识别可能错，后面的语音只会流畅地读出这个错误，因此多一种输出不等于多一层真实保证。

## 6. 常见误解

- 误解一：能处理图片就必然理解现实世界。图像基准通常只覆盖有限任务和场景。
- 误解二：视频只是一张更大的图片。视频还有时间、动作、顺序和可能的声音。
- 误解三：多模态系统对所有模态都一样好。能力需要逐模态、逐任务测试。
