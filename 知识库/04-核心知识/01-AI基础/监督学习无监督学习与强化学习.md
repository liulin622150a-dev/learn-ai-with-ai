# 监督学习、无监督学习与强化学习

## 1. 一句话说明

三者的核心区别是学习时获得“正确答案”、“无答案数据”还是“奖惩反馈”。

## 2. 生活类比

监督学习像做带答案的练习册；无监督学习像面对一桌没有标签的物品，自己按相似性分组；强化学习像练滑板，每次动作后从成功、失败或教练打分中调整策略。

## 3. 正式概念

监督学习（Supervised Learning）使用带标签的例子，学习输入到已知答案的关系。无监督学习（Unsupervised Learning）从无标签数据中找结构，聚类（Clustering）是常见任务。强化学习（Reinforcement Learning, RL）让智能体在环境中选动作，根据奖励或惩罚学习策略（Policy）。

## 4. 可视化原理

```text
带答案的例子 → 监督学习 → 预测标签/数值
无答案的数据 → 无监督学习 → 分组/结构
环境 + 奖惩     → 强化学习 → 行动策略
```

## 5. 现实例子

用已标记“垃圾/正常”的邮件训练过滤器，是监督学习；把没有类别名称的歌曲按声音特征自动分组，是无监督学习；让游戏角色根据得分和失分改进行动，是强化学习。一个复杂产品可能同时用多种方式。

## 6. 常见误解

- 误解一：“监督”指有人全程盯着。它主要指训练数据带有目标答案。
- 误解二：无监督学习会自动说出每个分组的人类含义。它只找结构，命名和解释仍需人判断。
- 误解三：强化学习就是“强力学习”。“强化”指通过结果反馈巩固策略。

## 7. 与其他知识的联系

三者都是 [[什么是机器学习|机器学习]] 的学习设置，不是三种完全独立的软件。[[什么是生成式AI|生成式 AI]] 的基础模型常先从大量数据中学习，后续还可加入监督或强化学习式调整。
因此，分类时要看学习信号，不只看产品外观。

## 8. 三道理解检查题

1. 复述：三种学习方式分别从什么信号中学习？
2. 比较：监督学习的“标签”和强化学习的“奖励”有何不同？
3. 应用：给“整理无标签照片”选一种方式，并说明理由。
