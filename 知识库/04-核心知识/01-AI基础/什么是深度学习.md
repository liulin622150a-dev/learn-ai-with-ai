# 什么是深度学习

## 1. 一句话说明

深度学习是使用多层神经网络从数据中学习层次特征的机器学习方法。

## 2. 生活类比

识别一辆自行车时，可以先看到线条，再组成车轮与车架，最后形成“这是自行车”的整体判断。深度网络像一支层层交接的检查队，较早层处理基础特征，较后层组合更抽象的模式。

## 3. 正式概念

深度学习（Deep Learning, DL）属于机器学习，核心工具是深度神经网络（Deep Neural Network）。Google 的机器学习术语表将深度模型说明为包含一个以上隐藏层的神经网络。“深”指计算层次，不指思想更深或拥有意识。

## 4. 可视化原理

```text
原始输入 → 基础特征 → 组合特征 → 抽象表示 → 输出
 照片       边缘/颜色      形状/部件       整体物体      类别
```

## 5. 现实例子

语音转文字系统需要处理声音中的局部变化、音素组合和语句上下文。深度学习能在多层中逐步形成表示，减少人把所有特征手工编成规则的需求。但背景噪声、方言和训练数据不足仍可以导致识别错误。
不同任务会使用不同网络结构，所以“深度学习”是一类方法，不是唯一模型名称。

## 6. 常见误解

- 误解一：深度学习等于全部 AI。它只是机器学习的一个分支，AI 还包含其他方法。
- 误解二：网络越深结果必然越好。层数也会带来训练成本、过拟合和调试难度。
- 误解三：深度模型能自动学特征，就不需高质量数据。偏斜输入仍会影响输出。
