# 规则系统与机器学习

## 1. 一句话说明

规则系统由人写出判断步骤，机器学习则从数据中学出预测模式。

## 2. 生活类比

规则系统像按食谱做菜：“水开后下面，再煮五分钟”都已写好。机器学习像吃过很多碗面后，从例子中归纳“什么样的面可能好吃”。前者可直接追踪步骤，后者更擅长处理难以穷举的模式。

## 3. 正式概念

规则系统（Rule-based System）把人类编写的条件和动作执行下去，常见形式是“如果……那么……”。机器学习（Machine Learning, ML）不要求人把每条判断逻辑都写完，而是用数据训练模型，再用模型处理新输入。

## 4. 可视化原理

```text
规则路线：专家经验 → 编写条件 → 执行结果
学习路线：数据示例 → 训练模型 → 新输入的预测
```

## 5. 现实例子

垃圾邮件过滤可以用规则：标题包含某些词就拦截。它也可以用机器学习：从已标记的垃圾与正常邮件中学习组合特征。现实产品常混合两者，例如先用安全规则拦截明确威胁，再让模型评估模糊情况。
选择时要看规则能否写清、数据是否足够，以及错误后果能否承受，而不是单纯追求更新的技术名称。

## 6. 常见误解

- 误解一：规则系统一定落后。对稳定、边界清楚且需要解释的任务，规则可能更合适。
- 误解二：机器学习不需要人。人仍要定义目标、选数据、测试错误并设置边界。
- 误解三：两者只能二选一。许多系统会把确定规则和统计模型组合使用。
