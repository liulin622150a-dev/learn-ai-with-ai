# AI 术语索引

这 30 个术语是第一版的共同语言。先读白话解释，再沿关联链接回到已学习的知识卡或对应课程模块。

### 人工智能（Artificial Intelligence / AI）

让机器完成通常需要人类感知、判断、学习或生成的任务的总称。

关联：[[04-核心知识/01-AI基础/什么是人工智能]]、[[03-知识地图/AI全景图]]

### 算法（Algorithm）

为解决一类问题而设计的一组明确步骤，像一份可重复执行的做事方法。

关联：[[04-核心知识/01-AI基础/什么是机器学习]]

### 模型（Model）

模型是从数据或规则中得到的“会做某类事的成品”，输入信息后会给出预测、分类或生成结果。

关联：[[04-核心知识/01-AI基础/什么是机器学习]]、[[04-核心知识/01-AI基础/什么是大语言模型]]

### 数据集（Dataset）

数据集是一批按某种方式收集和整理的样本，是许多机器学习模型练习和检验的材料。

关联：[[04-核心知识/01-AI基础/什么是机器学习]]

### 机器学习（Machine Learning / ML）

机器学习让系统从例子中找规律，而不是把每一条判断规则都由人提前写死。

关联：[[04-核心知识/01-AI基础/什么是机器学习]]、[[03-知识地图/AI全景图]]

### 监督学习（Supervised Learning）

监督学习像看带答案的练习题：模型用已经标注结果的例子学习输入和答案之间的关系。

关联：[[04-核心知识/01-AI基础/监督学习无监督学习与强化学习]]

### 无监督学习（Unsupervised Learning）

无监督学习像整理一箱没贴标签的物品：模型自己从数据中寻找相似性、分组或结构。

关联：[[04-核心知识/01-AI基础/监督学习无监督学习与强化学习]]

### 强化学习（Reinforcement Learning / RL）

强化学习让系统通过奖励和反馈反复尝试，逐渐学会在一连串选择中做得更好。

关联：[[04-核心知识/01-AI基础/监督学习无监督学习与强化学习]]

### 神经网络（Neural Network）

神经网络由许多简单计算单元连接而成，能把输入逐层转换成更适合完成任务的表示。

关联：[[04-核心知识/01-AI基础/什么是神经网络]]

### 深度学习（Deep Learning）

深度学习是使用多层神经网络学习复杂模式的方法，常用于图像、语音和语言任务。

关联：[[04-核心知识/01-AI基础/什么是深度学习]]、[[03-知识地图/AI全景图]]

### 生成式 AI（Generative AI）

“生成式”按输出能力分类：系统能根据输入产生新的文字、图像、声音、代码或视频；它不直接说明模型规模或采用哪条技术谱系。

关联：[[04-核心知识/01-AI基础/什么是生成式AI]]、[[03-知识地图/AI全景图]]

### 基础模型（Foundation Model）

基础模型强调在广泛数据上预训练后可适配多种下游任务；它描述通用性与适应性，不等同于“生成式”能力标签。

关联：[[04-核心知识/01-AI基础/什么是大语言模型]]、[[03-知识地图/大模型知识地图]]

### 大语言模型（Large Language Model / LLM）

大语言模型以语言为主要模态并具有较大规模；生成式 decoder-only LLM 能按上下文生成文本，但 encoder-only 等 LLM 不能仅因名称而等同于生成式 AI。

关联：[[04-核心知识/01-AI基础/什么是大语言模型]]、[[03-知识地图/大模型知识地图]]

### 多模态（Multimodal）

多模态表示系统能处理或连接不止一种信息形式，例如文本、图像、语音和视频。

关联：[[04-核心知识/01-AI基础/文本图像语音与视频]]、[[02-学习路线/第四模块-认识多模态]]

### Token（Token）

Token 是模型读写文本时使用的片段单位，不必等同于一个汉字、一个英文单词或一个字符。

关联：[[04-核心知识/01-AI基础/什么是大语言模型]]、[[02-学习路线/第二模块-理解大模型]]

### 参数（Parameter）

参数是模型在训练中不断调整的数值，用来保存它从数据中学到的模式。

关联：[[04-核心知识/01-AI基础/什么是大语言模型]]、[[02-学习路线/第二模块-理解大模型]]

### 训练（Training）

训练是让模型反复看数据、比较结果并调整参数的学习过程。

关联：[[04-核心知识/01-AI基础/什么是大语言模型]]、[[02-学习路线/第二模块-理解大模型]]

### 推理（Inference）

推理是训练完成后把新输入交给模型、由它计算并给出输出的使用过程。

关联：[[04-核心知识/01-AI基础/什么是大语言模型]]、[[02-学习路线/第二模块-理解大模型]]

### 提示词（Prompt）

提示词是交给生成式 AI 的任务说明和上下文，它会直接影响输出的方向、范围和格式。

关联：[[02-学习路线/第三模块-学会人机协作]]、[[03-知识地图/AI工具知识地图]]

### 上下文窗口（Context Window）

上下文窗口是模型一次能参考的输入和已生成内容的范围，超出范围的信息可能无法同时被考虑。

关联：[[04-核心知识/01-AI基础/什么是大语言模型]]、[[02-学习路线/第二模块-理解大模型]]

### 幻觉（Hallucination）

幻觉是模型给出看似流畅却不准确、无依据或编造内容的现象，因此重要信息需要核查。

关联：[[04-核心知识/01-AI基础/AI能做什么与不能做什么]]、[[02-学习路线/第六模块-建立判断力]]

### Transformer（Transformer）

Transformer 是一类擅长处理序列信息的神经网络架构，现代许多大语言模型以它为基础。

关联：[[04-核心知识/01-AI基础/什么是大语言模型]]、[[02-学习路线/第二模块-理解大模型]]

### 注意力机制（Attention Mechanism）

注意力机制让模型在处理当前内容时，按需要更关注输入中更相关的部分。

关联：[[04-核心知识/01-AI基础/什么是大语言模型]]、[[02-学习路线/第二模块-理解大模型]]

### Embedding（Embedding）

Embedding 是把文字、图片等内容转换成一组可比较数字表示的方法，使相近含义更容易被检索或计算。

关联：[[02-学习路线/第五模块-知识库与智能体]]、[[03-知识地图/智能体知识地图]]

### 向量（Vector）

向量是一串有顺序的数字，在 AI 中常用来表达内容的特征、位置或语义表示。

关联：[[02-学习路线/第五模块-知识库与智能体]]、[[03-知识地图/智能体知识地图]]

### RAG（Retrieval-Augmented Generation / RAG）

RAG 会先从外部资料中找出相关内容，再把这些内容交给模型辅助生成回答。

关联：[[02-学习路线/第五模块-知识库与智能体]]、[[03-知识地图/智能体知识地图]]

### 智能体（AI Agent）

智能体是在明确目标下，能选择步骤、调用工具并在检查点接受约束的 AI 系统设计。

关联：[[02-学习路线/第五模块-知识库与智能体]]、[[03-知识地图/智能体知识地图]]

### 工作流（Workflow）

工作流是把任务按固定或可判断的步骤串起来的过程，它可以自动化，但不一定就是智能体。

关联：[[02-学习路线/第五模块-知识库与智能体]]、[[03-知识地图/智能体知识地图]]

### API（Application Programming Interface / API）

API 是软件之间约定好的调用接口，让一个程序能以明确格式请求另一个服务的能力。

关联：[[02-学习路线/第三模块-学会人机协作]]、[[06-工具实验室/工具体验规则]]

### 基准测试（Benchmark）

基准测试用统一任务、数据和规则比较模型或系统表现，结果只说明特定条件下的表现而非全部能力。

关联：[[02-学习路线/第六模块-建立判断力]]、[[04-核心知识/01-AI基础/AI能做什么与不能做什么]]
